# Conxian Economy: Creator Freedom Operating Rules

## 1. Ethos & Vision
The Conxian economy is a creator-first, sovereign ecosystem designed to preserve freedom while ensuring alignment with the network's core ethos. It is built on the principle that value should be rewarded where it is created, and that builders, users, and agents should have clear, permissionless paths to contribute and earn.

## 2. Participation Model

### 2.1. Builders (Developers, Designers, Researchers)
- **Role:** Create the infrastructure, services, and tools that power the Conxian network.
- **Participation:** Through core development, bounty fulfillment, and independent service creation.
- **Value Creation:** Writing code, designing interfaces, performing security audits, and conducting protocol research.

### 2.2. Users (Consumers, Spaza shops, Institutional)
- **Role:** Utilize Conxian services for settlement, payments, and decentralized finance.
- **Participation:** Using the Gateway to access sovereign services and Bitcoin layers.
- **Value Creation:** Providing liquidity, generating transaction fees, and expanding the network effect.

### 2.3. Agents (AI Agents, Automated Systems)
- **Role:** Facilitate complex operations, automate settlement, and manage risk.
- **Participation:** Running as TEE-verified entities or autonomous service providers.
- **Value Creation:** Improving efficiency, providing real-time risk assessment, and executing automated state proposals.

### 2.4. System-Level Economies (DAO, Treasury, CSF)
- **Role:** Govern the network, manage resources, and ensure long-term stability.
- **Participation:** Participating in governance votes, managing treasury allocations, and overseeing the Conxian Stability Fund (CSF).
- **Value Creation:** Ensuring protocol safety, funding ecosystem growth, and maintaining the 5/5/90 productive streaming behavior.

## 3. Contribution Paths & Reward Logic

### 3.1. Contribution Paths
- **Bounties:** Explicit tasks defined by the community or core team with fixed rewards.
- **Core Development:** Ongoing maintenance and enhancement of the Gateway and protocol libraries.
- **Ecosystem Growth:** Creating new sovereign services or integrating additional Bitcoin layers.
- **Security & Auditing:** Identifying vulnerabilities and providing remediation artifacts.

### 3.2. Reward Logic (Proof-of-Work & Impact)
- **Proof-of-Work (PoW):** Rewards are tied to verifiable artifacts (code, documentation, audit reports).
- **Impact-Based:** High-impact contributions that improve network security or TVL are prioritized.
- **Transparency:** All rewards and payout decisions are recorded on-chain or in public audit logs.

## 4. Guardrails & Operating Rules

### 4.1. Quality & Trust
- **Verified Artifacts:** Payouts for bounties and core work require concrete, maintainer-verifiable evidence.
- **Code Standards:** Adherence to standard Rust/TypeScript conventions and security best practices.
- **Audit-Ready:** All production code must be audit-ready and free of testnet contamination.

### 4.2. Alignment & Ethos
- **Sovereign-First:** Prioritize non-custodial and decentralized solutions.
- **Bitcoin-Native:** All value must ultimately settle or be anchored to Bitcoin/Stacks.
- **Freedom-Preserving:** Avoid centralized gates that stifle innovation or participation.

### 4.3. Risk Management
- **TEE Floor:** Critical settlement and execution logic must run within a Trusted Execution Environment.
- **Timelocks:** Mandatory 144-block timelocks for external settlement triggers to ensure security.
- **Risk Scoring:** Continuous assessment of Data Availability, Settlement, and Bridge Security for all layers.

## 5. Implementation Guidance

### 5.1. Product Decisions
All new products must include a sustainability model that contributes to the network's revenue flows (e.g., protocol fees).

### 5.2. Bounty Decisions
Bounties should be used to decentralize development and reward independent contributors for specific, high-priority tasks.

### 5.3. CSF Launch Decisions
The Conxian Stability Fund (CSF) launch must be gated by full production readiness, including verified wallet architecture and signer controls.

## 6. Governance & Evolution
The Conxian economy is not static. It evolves through governance participation, where stakeholders can propose changes to operating rules, reward logic, and guardrails to ensure the network remains competitive and aligned with its creators.
