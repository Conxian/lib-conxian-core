# Support

This repository follows Conxian's parent-level governance defaults (policy docs, templates, and shared workflows).

## Repository Classification & Support Tier

`lib-conxian-core` is categorized as **Primary Strategic Platform Core (Tier 1)** within the Conxian ecosystem.

- **Primary Audience:** Protocol engineers, security auditors, SDK integrators, and infrastructure builders.
- **Response SLA:**
  - **Non-Security Issues & Bug Reports:** Initial triage and response within **48 hours** (business days).
  - **Security Vulnerabilities:** Initial acknowledgement within **48 hours** and triage within **5 business days** per [SECURITY.md](SECURITY.md).

## Where to get help

- **Bug Reports & Issues:** Open a GitHub issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Governance & Feature Requests:** Open a GitHub issue using the [Governance Request Template](.github/ISSUE_TEMPLATE/governance_request.yml).
- **Bounty Job Cards & CXN Bounties:** Refer to [CXN Bounty Job Card Template](.github/ISSUE_TEMPLATE/cxn_bounty_job_card.yml).
- **General Support Email:** Contact `support@conxian-labs.com`.

## Repository Ownership & Scope

For a detailed breakdown of what `lib-conxian-core` owns vs. downstream crates (such as `conxian-gateway` or `conxius-enclave-sdk`), refer to [docs/governance/REPO_OWNERSHIP.md](docs/governance/REPO_OWNERSHIP.md).

## Security vulnerabilities

Do **not** report vulnerabilities in public issues.

Follow the private reporting process in [SECURITY.md](SECURITY.md) (GitHub private advisories or `security@conxian-labs.com`).
